# Definition of Done (DoD)

Una tarea se considera TERMINADA cuando:
1. El servicio está configurado y funcionando en su VM.
2. Está documentado en /docs (pasos, decisiones, capturas).
3. Se ha probado con evidencia (captura, log o test).
4. El cambio se ha subido vía Pull Request y revisado por el compañero.
5. El Issue está cerrado y vinculado al Milestone.
