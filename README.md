# Nexvirt — Mini infraestructura empresarial virtualizada

> "Una empresa completa en un único laboratorio virtualizado."

## Equipo
- Biel Duarte
- Cristian Sánchez

## Ciclo formativo
ASIX1 — Administración de Sistemas Informáticos en Red

## Objetivo del repositorio
Alojar el diseño, la implementación y la documentación de una
infraestructura IT completa (AD, DNS, DHCP, web, almacenamiento,
backups, firewall y monitorización) sobre un único entorno virtualizado.

## Problema que resuelve
Las pequeñas empresas gestionan sus servicios IT de forma aislada,
sin control centralizado de usuarios, sin backups ni monitorización,
y con hardware costoso.

## Arquitectura (resumen)
Internet → Firewall → Switch virtual → 5 VMs sobre VMWare o VirtualBox

## Plan por sprints
